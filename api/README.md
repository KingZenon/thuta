# Property Portal API

Prisma ORM 7, SQLite, Express, and TypeScript API for the property portal.

## Local setup

1. Copy `.env.example` to `.env`.
2. Run `npm install`.
3. Run `npm run db:migrate -- --name init`.
4. Run `npm run db:seed`.
5. Run `npm run dev`.

Demo credentials are printed by the seed command and documented in the parent workspace README.
